## Requirements & Constitutional Compliance

- **SCri006:** The runtime preserves the defined modular pipeline boundaries
  and typed stage adapters instead of passing unstructured stage data.
- **SCri007:** The CLI and pipeline support the required `eye_only` and
  `eye_yawn` experiment paths without duplicating decision logic.
- **SCri016:** The runner reports processing and run-level metrics while
  retaining frame-order and temporal state semantics.
- **FReq024 — configuration decoupling:** Operational thresholds and alert
  settings are loaded from the selected YAML configuration; CLI mode overrides
  are in-memory only.
- **FReq025 — decision modes:** `eye_only` and `eye_yawn` are explicitly
  selectable and exercised by the integration suite.
- **FReq030 — invalid measurement safety:** Missing faces and invalid geometry
  emit `UNKNOWN` eye, mouth, and decision states. Missing data is never
  reclassified as `DROWSY`, and an isolated blink is not drowsiness.
- **FReq032 — graceful exit:** EOF, user interruption, frame limits, stage
  failures, and partial initialization reach cleanup. Capture, GUI, detector,
  temporal, and alert resources are released through the finalization path.
- Raw datasets, model assets, configuration files, dependency manifests, and
  `AGENTS.md` were not modified by this task.
