## 1. Executive Summary

Task T0201 provides a command-line utility that downloads, extracts, and
verifies D3S video assets under `data/raw/d3s/`. The implementation preserves
the archive's subject, session, and behavior directory structure so video data
is never flattened or mixed across subjects.

The downloader uses Python's standard-library `urllib`; therefore `requests`
and `gdown` are not required. OpenCV performs video readability checks, while
NumPy supports generated video fixtures in the unit tests. The project
dependency list now also declares Pytest, Flake8, and Black so the T0201 tests
and mandatory quality gates can be reproduced from `requirements.txt`.

## 3. Guardrail Validation

- **No absolute paths:** repository and data paths are derived with
  `pathlib.Path` from the script location.
- **Data isolation:** extraction preserves the source hierarchy and never
  shuffles, splits, or relocates frames between subjects or videos.
- **Extraction safety:** resolved archive members must remain below the
  configured output directory.
- **Resource cleanup:** OpenCV captures and writers are released in `finally`
  blocks; network and archive streams use context managers.
- **Actionable errors:** network, invalid archive, unreadable video, and
  insufficient video count conditions return explicit failures.
- **Raw-data protection:** Git ignore checks matched the repository rules for
  both MP4 and ZIP files under `data/raw/d3s/`.

## 6. Limitations and Follow-up

The live, potentially large D3S archive was not downloaded during this task
report run. Network availability, Google Drive sharing permissions, archive
size, and full-dataset transfer time therefore remain environment-dependent.
The local-archive workflow and all extraction and verification behavior were
validated with generated MP4 fixtures.

WP03 can consume the preserved subject/video hierarchy when implementing
ordered video acquisition. Any future dataset split must remain grouped by
subject where feasible, otherwise by complete video or session.
